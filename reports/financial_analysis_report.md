# Financial Analysis Report

## Method

The project uses a signed ledger: revenue is positive except for refunds/credit notes; COGS, operating expenses, interest, and tax are negative. Gross profit equals revenue plus COGS; net profit equals all income-statement categories. Ratios return unavailable values when a denominator is zero.

## Limitations

Figures are synthetic, generated from deterministic assumptions, and do not represent an audited financial statement. Balance-sheet and cash-flow records are modeled monthly. Statistical outliers are not fraud determinations.
